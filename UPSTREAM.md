# Upstream provenance

Arclume began as a modified fork of
[italomandara/Procyon](https://github.com/italomandara/Procyon). This private
repository starts as an independent, LFS-backed source snapshot so its history
does not copy unrelated upstream development history.

The upstream repository remains the reference for original copyright notices.
`LICENSE.txt`, `NOTICE.md`, and `THIRD-PARTY-NOTICES.md` remain part of every
source and binary distribution workflow.
