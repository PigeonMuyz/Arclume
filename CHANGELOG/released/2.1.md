# Arclume 2.1

## 运行环境

- Arclume Runtime 支持 D3DMetal 4 Beta 3 与 DXMT 0.80，可在游戏运行设置中切换。移除了 D3DMetal 3 选项。
- 首次设置可选择预编译的 Arclume Runtime 或在本机编译 Nefinita。Nefinita 会获取与构建配方匹配的源码和依赖。
- 运行环境页面集中显示组件下载进度和就绪状态。已准备好的运行时可以在设置中切换。

## 剑网 3

- 在游戏主页的「更多操作」中可以优化 DXMT 着色器。支持读取游戏资源中的 DXBC、已有 DXMT 缓存或外置着色器，显示处理数量和预计剩余时间，可在开始前调整处理线程数。已保存的优化进度可以继续处理。
- 修复导入后出现重复的「剑网 3 系列启动器」条目。首次安装时等待游戏生成 `config.ini`，再补齐启动所需的配置，保留原文件里的其他设置。
- 运行设置中加入隐藏的「跳过启动器，直接启动游戏」。在该面板按 `↑↑↓↓←→←→`（即上上下下左左右右）或 `WWSSAADD` 可显示开关。

## 游戏库与设置

- 运行设置改动即保存，包括图形方案、启动参数、Metal 性能面板和剑网 3 的直启开关。移除了手动保存与重置按钮。
- 加入容器管理入口和控制器游戏侧栏，改善游戏库、剑网 3 公告阅读与首次引导。

## 安装

- 需要 macOS 26 或更新版本。在首次设置或「设置 → 运行环境」下载所选运行时及图形组件。
- 应用更新沿用现有游戏设置与容器。DXMT 着色器优化与 D3DMetal 各自使用独立缓存。
