# Arclume 2.0 · 全新 UI 设计

- 宽屏启动器与游戏专属背景／标志，搭配可折叠、可拖动排序的图标侧栏。
- 原生风格的已安装应用启动台、重设计的设置和项目资料编辑器。
- 全窗口欢迎页、箭头教学、可选的旧版迁移和 Steam／剑网3初始化。
- 记住上次选择的项目；游戏库先显示缓存，随后在后台刷新。
- Steam／App Store 等资料匹配，补全背景、标志和简介。
- 修复开始游戏按钮仅文字可点击的问题，Wine Dock 图标等比例缩小并保留透明边缘。
- 随附 YY 专用适配与 Wine 加载锁顺序补丁。

## 已知问题

**YY 在麦序模式下可能仍出现交互无响应。** 本次不宣称所有频道模式与长期语音会话均稳定。

## 升级说明

旧版容器通过应用内升级流程合并至 `Arclume/ALBottles`，完成校验后清理旧容器，不保留重复副本。应用替换与 Runtime 更新不覆盖游戏存档。

no-runtime 仍使用下载／初始化 Runtime 的方式，本次不包含在用户电脑上从源码编译 Wine。
