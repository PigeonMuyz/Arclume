# 更新到 D3DMetal 4 Beta 3

- 从 Apple 官方 Evaluation environment 4.0 Beta 3 的完整 redist 同步图形组件，保留原始签名和许可材料，固定新归档的 SHA-256、体积及内容寻址下载路径。
- 移除 D3DMetal 3 的源码资源、下载项和界面选项，旧图形偏好在加载、重置和自动配置时统一为 D3DMetal 4；硬件不支持时明确提示。
- 启动前验证框架版本为 4.0b3，拒绝旧 Beta 2 解包缓存；macOS 26 使用该组件的 Metal 3 后端，macOS 27 及以后按 Apple 说明启用 Metal 4 后端。
- 安装时将 Unix 模块链接到同一份共享库，修复复制成多份二进制引发的设备创建崩溃；已有相同内容的错误副本也会重新链接。
- Wine Runtime 与 Prefix ABI 沿用当前合同。升级只替换运行组件，保留游戏容器；回退需使用旧 App 及其固定组件清单。
- 无签名 Debug build 和 69 项相关核心测试通过。macOS 27.3 的独立 Runtime / 新 Prefix 中，D3D11、D3D12 设备创建、交换链、绘制、缩放及再次 Present 通过。实际游戏与 macOS 26 的实机行为须分别验收。
