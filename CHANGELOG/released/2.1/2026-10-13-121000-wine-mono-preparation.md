# 自动准备 Wine Mono

- 用户选择/准备运行时后，先校验并缓存 Wine 11 所需的 Mono 10.4.1；优先复用 Arclume Runtime 已带的包，否则获取固定的官方 MSI。
- 创建容器时同样先准备 Mono；设置中再次点击当前运行时卡片可补全缓存，不必切换到另一个运行时。
- 使用 Wine 支持的专用缓存环境变量，让初始化从本地安装包自动安装，不再等待 Wine 下载确认弹窗。不禁用 mscoree，不伪报 .NET 已安装。
- 下载按文件落盘并校验大小/SHA-256；网络失败继续由 Arclume 展示重试，不在启动游戏时偷偷联网。
- 无容器迁移/重置；只增加 Arclume 管理的缓存。现有 runtime 与容器不在开发验证中改动。
- 待手工验证：两种运行时首次初始化和切换、断网重试，以及实际 .NET 应用启动。
