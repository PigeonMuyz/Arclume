# Arclume 2.0 · 全新 UI 设计（重新发布，构建 13）

本次以最新测试通过的代码重新发布 2.0，包含此前的迁移修复与本轮重置修复。

## 全新界面

- 宽屏启动器、游戏专属背景与标志，可折叠并拖动排序的图标侧栏。
- 原生风格的已安装应用启动台，重新设计的设置和项目资料编辑器。
- 全窗口欢迎页、箭头教学，可选的旧版迁移与 Steam／剑网3初始化。
- 记住上次选择的项目；游戏库先显示缓存，再在后台刷新。
- Steam／App Store 等资料匹配，补全背景、标志和简介。
- 开始游戏按钮支持整个按钮区域点击；Wine Dock 图标等比例缩小并保留透明边缘。

## 升级与重置修复

- 降低旧容器迁移的内存占用，不读取游戏文件内容或执行文件哈希校验；保留空间、路径与中断恢复保护。
- 自动处理旧容器内置系统组件差异，修复符号链接可能导致后续目录漏扫的问题。
- 修复确认重置后无响应，以及下次打开时因应用设置访问错误而停在“重置尚未完成”的问题。
- 补充运行时版本选择、升级阶段及启动失败错误码日志，方便定位其他设备上的异常。

旧容器通过应用内流程合并至 `Arclume/ALBottles`，成功完成后移除旧副本。普通升级不会主动清除游戏存档；**“重置设置和应用数据”是独立的有损操作，会将整个应用支持目录移入废纸篓并清除设置。**

## 验证与已知问题

- 本机已由用户验证：1.0.3（8）初始化两个旧容器并成功启动剑网3启动器，再升级迁移至本轮代码后仍可启动。其他用户报告的 CPU 类型错误尚未复现，不能据此认定全部解决。
- 沿用 Arclume Wine 1.1.2，随附 YY 适配与加载锁顺序补丁。**YY 在麦序模式下可能仍出现交互无响应。**
- 已安装旧 2.0、2.0.1 或 2.0.2 的用户请手动下载安装本次构建；这些版本的更新检查不会将重发的 `v2.0` 识别为更高版本。
- no-runtime 继续采用下载／初始化 Runtime 的方式，不包含用户侧源码编译 Wine。
