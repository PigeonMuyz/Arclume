# Arclume 2.0.2 · 旧版容器自动合并修复

- 修复旧容器中的内置系统组件差异阻止升级的问题：自动保留基础容器的配置、ADO、OLE DB、IE、Windows Media Player 和写字板组件，不再因此停在“有应用数据需要进一步检查”页面。
- 修复符号链接可能导致后续真实目录被漏扫的问题，确保容器内的游戏文件参与迁移，同时不跟随外部链接。
- 延续 2.0.1 的低内存迁移，不扫描游戏文件内容、不执行哈希校验。保留磁盘空间、路径边界和中断恢复保护。

## 升级说明

如果 2.0.1 的迁移报告列出上述系统组件冲突，请安装 2.0.2 后重新检查并继续迁移，不需要手动删除文件、旧容器或迁移记录。

已完成迁移的用户不需要重复迁移。真正的同名游戏文件、存档或不安全路径冲突仍会受到保护，不会为强行合并而静默覆盖。

本次沿用 Arclume Wine 1.1.2，包含 YY 适配补丁。**YY 在麦序模式下可能仍出现交互无响应。**
