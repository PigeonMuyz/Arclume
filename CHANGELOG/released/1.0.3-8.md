# Arclume 1.0.3（8）

## 本次更新

- 更换紫蓝色 A 应用图标，提供完整 macOS 多尺寸资源。
- 完善剑网 3 画质预设与显卡配置，整理设置布局及可选简洁首页。
- 完善 Steam 下载、初始化恢复、中文字体、安装入口和停止 Windows 程序的反馈。
- 支持自定义 Windows 安装程序与 ZIP／7z／RAR 绿色软件导入、整包替换更新及受限绿色适配。
- 游戏库补充 GameDB／Steam 元数据关联、无封面时的程序图标展示，以及按程序精确匹配的名称规则。
- 增加游戏、关联数据及启动器的移除流程与关联依赖提示；只有明确确认的范围才执行移除。
- 终末地与鹰角启动器采用独立 JSON 适配规则，完善直接启动、安装路径与关联识别。
- 重写测试入口，区分核心测试与显式隔离的 UI 测试。

## 兼容性说明

- 图形设置收敛为内置 Wine 的 D3DMetal 3／4 选择，移除旧 GPTK 实验开关和 CrossOver 模式入口；既有外部容器不自动迁移或删除，旧关联可能需要重新配置。
- 内置 Wine 的版本与校验信息以本标签下 `arclume-wine-runtime.json` 为准，本次不替换 Runtime 归档。
- YY 已有手动诊断组合通过本机频道显示与交互测试，但仍依赖独立实验 Runtime、DNS／OSR 内存补丁和进程内绘图模式。**该组合未接入普通启动，不代表本版本默认修复 YY。** 麦克风收发、长期通话及无调试器重启仍待验证。
- 诊断工具保留在源码 `script/diagnostics/`，不会随应用自动执行，也不会默认打开 CEF 调试端口。

## 下载与验证

- with-runtime：包含 Manifest 指定的内置 Wine 归档。
- no-runtime：不包含 Wine 归档，适合已有 Runtime 的用户。
- 两种 DMG 均附 SHA-256；签名／公证状态以 GitHub Release 说明为准。
- 发布流程不清理用户游戏、存档、账户、配置或日志。
