# Arclume 2.0.1 · 迁移紧急修复

- 修复旧版迁移检查中临时内存持续增长的问题，降低大型游戏库升级时因内存压力退出的风险。
- 迁移不再扫描游戏文件内容或执行哈希校验，只读取目录和文件基本信息；复制交由系统完成，不将整个游戏文件加载到内存。
- 保留路径与磁盘空间检查、迁移中断恢复；移除不准确的“校验成功”提示。

## 升级说明

遇到 2.0 迁移检查退出的用户，请先安装 2.0.1，再打开应用重试。不要手动删除旧容器或迁移记录；已完成迁移的用户无需重复迁移。

不再执行逐字节内容校验，复制失败仍会中止切换。不同容器的同名应用文件无法确认相同时会暂停合并，不以文件大小相同为由覆盖或丢弃文件。

本次沿用 Arclume Wine 1.1.2，包含 YY 适配补丁。**YY 在麦序模式下可能仍出现交互无响应。**
