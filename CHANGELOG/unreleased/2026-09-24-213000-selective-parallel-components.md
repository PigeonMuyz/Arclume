# 按运行时版本独立补全组件

- 下载前展示所选组件、预计下载量；设置和初始化允许逐项下载，不再将全部发布资源视为必装组件。
- 依赖绑定运行时 ID 和精确版本。Wine 1.1.2 升级仅下载 Wine；Steam/剑网3初始化额外请求硬件适用的 D3DMetal 和字体，剑网3图形增强独立可选。
- 当前 Wine 不提供 CrossOver 专属 DXMT、GStreamer、兼容修补包下载入口；保留发布清单及不可变归档记录，不影响旧版资源兼容。
- 下载任务最多三路并行；大于等于 24 MiB 的单文件在服务器明确支持 Range 时分三段下载，共享三路网络上限。不支持 Range 则使用单流，错误范围响应不得拼接。分片以 1 MiB 缓冲合并。
- 进度按总字节汇总并展示平均速率；文件落盘后再做流式校验，已完成组件可复用，失败不覆盖旧运行时。
- 不迁移、重置或清理用户容器；运行时激活仍等待 Windows 程序退出。未上传新资源、DMG 或发布版本。

验证：7 个核心套件共 40 项通过，覆盖精确版本依赖、单项选择、硬件图形后端、并发上限、真实本机分块 HTTP 进度、取消和缓存保留；21 项分发脚本测试通过。`./script/pr_preflight.sh`、`git diff --check`、已配置下载服务的 Debug 构建及 ad-hoc 签名校验通过，App 无运行二进制资源。

实际 OSS 只读 HEAD 和 64 KiB Range 探测确认 Wine 归档支持分段，状态码、总长和范围正确；未用完整归档测速，未执行用户容器初始化或游戏启动。
