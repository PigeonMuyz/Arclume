# 运行组件目录与显式下载

- 运行资源改为无服务器地址的固定组件清单，按类型、名称、ID、版本和 SHA-256 分发；初始化和设置页由用户点击下载。
- 下载落盘后流式校验，完成标记与暂存目录隔离半成品；组件查找优先使用本地下载缓存，普通游戏启动不触发下载。
- 停止独立查询 GitHub Wine 更新，运行环境版本遵循 App 审核过的组件清单；保留将来多引擎、预编译与本机构建策略的元数据接口，本版不提供本机构建。
- 下载基础地址在构建阶段注入，不提交服务器地址或密钥；错误提示不显示下载地址。
- 下载清单必须与 App 内置 Runtime Manifest 完整匹配，拒绝替换到不同版本、架构或 ABI。更换运行时期间关闭启动门，避免新游戏进程与安装发生竞争。
- 兼容性：保留旧安装包资源查找回退与现有 Runtime ABI 检查，不修改、迁移或删除容器。回滚不清理本地组件缓存。
- 验证：`./script/pr_preflight.sh` 通过，无签名 Debug App 不含运行归档或 Wine/D3D 二进制；指定的下载、兼容、更新包选择、启动门和手柄排序测试共 24 项通过。构建与发布固定使用已锁定依赖版本，不顺带升级依赖。
- 尚未验证：真实 OSS 首次下载、断网重试、运行时占用及旧版容器启动；本次未访问用户容器，也未签名发布或替换 Applications。
