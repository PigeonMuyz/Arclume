# 内置 Wine Runtime 1.1.0

- 内置 Runtime 更新至 Arclume Wine 1.1.0（Wine 11.0，FineWine Endfield 补丁集）。
- 归档与 Manifest 使用同一 SHA-256，首次启动时会在原 Runtime 位置原子替换；Games 容器与游戏文件不迁移、不重建。
- 新 Runtime 的 Wine 主进程携带 macOS 麦克风输入权限；应用侧仍会在首次启动内置 Wine 前请求系统授权。

兼容性：`runtimeABI` 与 `prefixABI` 保持不变，现有剑网 3 Games 容器可直接复用。若需回退，可在更新设置中安装兼容的旧 Runtime，容器数据不会被删除。
