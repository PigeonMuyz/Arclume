# 启动器与弹窗当前交付状态

本记录汇总本轮实际提交结果；同日其他记录保留迭代过程，涉及冲突时以本记录为准。

- 普通游戏库统一为宽屏启动器；侧栏底部的“全部游戏”入口展示启动台式图标面板，实际仅包含已安装项目，不再提供已安装/全部筛选。保留搜索、悬停反馈、选择后切换展示与 Escape 关闭，不因选中而启动游戏。
- 停止读取 Steam 账户完整库存，继续扫描本地多个 Steam 库的安装清单与获取单个游戏的展示资料；旧快照中过期的未安装占位不再恢复。
- 移除查看详细信息入口与旧详情面板。更多菜单统一安装目录、运行设置、编辑项目信息，剑网3额外提供画质设置。
- 主操作按应用图标取色，降低非剑网3背景模糊；共享弹窗统一标题和关闭控件。设置页使用原生分组表单与侧栏。
- 编辑器最终采用左侧背景/标志预览、右侧名称/简介的左右布局，取消早期的三个标签方案。资料查询收进“匹配资料…”弹窗，保存前均为草稿；剑网3预览支持本地缓存的官方标志。
- GameDB 与单个 Steam 商店资料支持预览采用；本地化依赖精确 Steam 映射，有缺失时使用原文，不保证所有游戏都存在当前语言资料。JSON 可提供静态展示适配；动态资讯仍需要代码读取器，并非任意 JSON 即可接入所有资讯源。
