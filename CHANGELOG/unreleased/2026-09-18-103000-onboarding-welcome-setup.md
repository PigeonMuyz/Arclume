# 欢迎、教学和初始化统一为全窗口流程

- 项目编辑器仅预览当前项目，移除预览中的游戏侧栏，保留宽屏布局。
- 恢复带分层动态图标的全窗口欢迎页；随后在实际界面上演示功能，再用同样的页面选择可选配置。
- 欢迎与教学阶段分离，教学单独编号；第一项禁用上一步，返回只在教学步骤间移动，不跳回欢迎页。
- 修复开始游戏与更多菜单的引导锚点：测量按钮外层布局，并忽略已脱离窗口的旧锚点。
- 检测到未迁移旧容器时，先展示不加载旧库、不采纳运行时偏好的演示教学，再询问迁移；拒绝迁移可退出，不提前启动新架构。
- 保留既有迁移事务、校验和恢复机制；未完成的迁移直接进入恢复流程，不重复教学，不自动执行收尾。
- 剑网3与 Steam 初始化沿用欢迎页的全窗口样式；用户明确操作后才准备环境/下载安装器，第三方 Windows 安装器仍使用自己的窗口。
- 不修改 Runtime、版本或发布配置；不自动重置引导完成标志，不在开发验证时迁移用户数据。

手工验证：欢迎 → 教学（含开始/更多箭头）→ 可选配置；旧数据检测 → 演示 → 迁移确认/退出；配置剑网3后接续 Steam；检查失败/取消时保留旧数据。
