# 普通模式游戏入口与 Steam 安装衔接

- 普通模式发现已配置运行时的剑三 Games 容器，显示独立剑三卡片；复用启动、停止、画质及高级设置，不借用当前 Steam 容器。后续网游可以增加对应识别与启动适配。
- 剑三身份不再依赖界面模式。普通模式内的剑三高级设置暂不切换运行时，迁移仍从剑三模式发起。
- 底部工具区改为带文字的添加游戏、容器菜单、工具入口，移除重复设置按钮；容器管理直达运行时设置，筛选无结果时显示提示，底部操作区不再覆盖卡片。
- CrossOver / 内置 Wine 新建 Steam 容器后自动下载 Valve 官方 Windows 安装程序并打开交互式安装向导；提供进度、取消下载、本地安装包与重试入口，安装完成后自动刷新。已有 Steam 不重复安装。
- 安装目标绑定创建时的容器，设置关闭后继续显示后台进度；校验下载状态和大小（100 MiB 上限），不自动接受 Steam 协议。安装包在安装进程退出后清理。
- 切换模式保存并恢复各自容器，进入剑三模式前恢复 Games 容器再检查引导；已完成配置不重复展示完成页面。运行时升级与配置缺失仍保留原更新/修复入口。

## 验证

- Debug 构建、PR preflight、git diff --check；不运行 XCTest。
- 待手工验证：双运行时新建 Steam 容器的完整下载/安装、网络失败重试与本地安装包、标准/剑三反复切换、剑三卡片启动与停止。
- 不移动、复制或重置用户容器与游戏文件；不修改 Runtime 归档，不发布或替换已安装应用。
