# 自动获取 Nefinita 构建材料

- 移除源码目录选择，用户确认准备 Nefinita 后自动获取固定提交的 13 个构建输入，再由上游脚本下载 Wine 源码、依赖与补丁。
- 优先从配置的组件下载服务获取；未配置或网络/文件不可用时回退到 GitHub 固定提交的原始文件，不克隆完整历史、不传递开发者凭据。
- 输入文件最多三路并发、下载到磁盘，逐文件校验固定 SHA-256 后才发布可复用缓存；哈希异常不回退、不执行。校验值只适用于构建材料，不扫描用户游戏数据。
- 下载地址不出现在用户错误中。上游私有且 OSS 材料尚未发布时明确提示暂时不可用，不重新要求用户选择本地源码。
- 没有上传构建材料或工具包、没有公开私有仓库。Nefinita 编译及实际游戏运行仍需完整验收。
