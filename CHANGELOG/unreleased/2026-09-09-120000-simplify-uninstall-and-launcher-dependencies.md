# 简化卸载确认与启动器关联游戏处理

- 卸载窗口收敛为“仅卸载，保留游戏数据”和“移除全部”两档；详细路径、大小及结果折叠显示，去掉逐文件分类勾选。
- 支持直接卸载鹰角启动器；有游戏时提示可能影响启动和大版本更新，并提供默认关闭的“一并移除关联游戏”。未知/未完整识别的游戏保留并禁止合并删除。
- JSON 声明启动器专属子项与版本目录。仅卸载启动器时保留 `games`、未知内容和所有游戏入口；不会把包含游戏的启动器根目录整个移到废纸篓。
- 合并卸载复用游戏数据清理与注册表恢复片段机制；默认保留数据，选择“移除全部”才清理所选游戏已识别数据。部分失败如实报告已完成项并保留未删除游戏入口。
- 新增隔离测试覆盖未入库游戏发现、只卸载启动器保留游戏、未知内容保护和符号链接拒绝。实际用户文件未删除，Runtime/发布无变化；未运行 UI XCTest。
- 验证：LauncherRemovalTests、GameAssociatedDataTests、LibraryLifecycleTests、WindowsGameLaunchRulesTests 共 22 项通过；`./script/pr_preflight.sh` 无签名 Debug/Runtime 校验通过，`git diff --check` 通过。实际系统废纸篓操作未测试，fixture 使用临时回收目录验证移动行为与部分失败报告。
