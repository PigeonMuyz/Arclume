# 统一容器与程序内安全迁移

- 新架构统一使用 `Application Support/Arclume/ALBottles`，普通库与启动器样式共用同一份应用数据，不再切换剑网 3 运行模式。
- 首次升级先展示迁移检查和确认页，迁移完成前不实例化游戏库、安装入口或 Wine 预热。仅扫描 Arclume 管理的旧容器；第三方 CrossOver、外部游戏库不搬迁。
- 迁移采用复制、SHA-256 校验、源状态复核、记录事务后切换；应用文件、有效盘符和应用注册表冲突阻止迁移。系统差异需用户确认保留基础容器版本。
- 原容器、偏好、合并报告和事务记录保留在 `ContainerMigrationRecovery`。旧路径映射到统一容器，升级偏好中的路径和书签读取；异常中断由下次启动的恢复入口处理。不会自动删除旧数据。
- Steam 为可选配置；自动发现多个本机/容器 Steam 库。底部操作收为可展开按钮，筛选只显示已安装/全部；启动器式主界面不再是单个游戏弹窗。

## 兼容性与回退

- Windows 系统文件和公共注册表采用基础容器版本，迁移确认页列出差异。不同版本依赖可能需要重新修复；应人工验证 Steam、剑网 3、终末地和 YY 音频/频道。
- 不自动导入第三方 CrossOver 容器，不重建 Runtime，不变更 Manifest/归档或版本号。
- 迁移完成页进入应用前支持恢复；中断后提供恢复入口。进入应用后不要直接换回旧版运行旧路径（它们指向新容器）；请按 `docs/unified-container-migration.md` 检查恢复副本。
- 核心测试只创建隔离临时容器，不迁移本机用户容器。UI/真实游戏回归需要手工验证。
