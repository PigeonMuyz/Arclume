# 剑网 3 显卡配置伪装与恢复默认

- 高级设置增加「显卡型号伪装」，默认关闭；提供用户反馈配置中的 RTX 3060 预设，并支持从 machine_config.ini 导入其他 GPU 预设（每个游戏目录最多保存 20 个自定义预设）。
- 仅写入 Performance 的 GPUScore / GPUType / GPUName / VideoType / BDType，以及 Device 的 Count / Description_*。DLSS、DX12、磁盘和其他配置不随导入更改。这是游戏配置层的伪装，不更改 Wine/DXGI 的实际设备能力，也不保证解锁 DLSS 或探索。
- 首次启用前保存原始文件到同目录 arclume-gpu-profile-state.json，后续切换 GPU 不覆盖原始恢复基线。恢复默认还原原有显卡字段，删除伪装新增字段，保留期间用户对其他设置的修改；记录保留以供恢复与问题排查。
- 应用、导入、恢复异步显示进度；启动器/游戏运行时禁用修改，配置变动检测失败时不覆盖新文件。写入前先保存恢复记录，未完成操作可重试，下一次启动前也会重新应用选择或完成待恢复操作。
- 内置预设独立放在 jx3-gpu-profiles.json，方便后续增加其他显卡。未自动应用到真实 Games 容器；不修改 Runtime、不触发发布。
- 验证：临时文件覆盖首次应用、连续切换、恢复不存在/已存在设备段、保留独立设置、重复恢复、导入校验和启动前重应用；无签名 Debug 构建，不运行 XCTest。DLSS/预设解锁效果与 UI 操作需真机验证。
