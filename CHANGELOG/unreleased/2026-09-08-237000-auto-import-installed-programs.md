# 安装后自动添加游戏库入口

- 自定义安装前记录容器程序快照，后台有界扫描新增/变化的 EXE 和 Windows 快捷方式，排除安装器、卸载器、更新器以及系统/缓存目录。
- 安装宿主退出且新快捷方式及目标文件连续稳定 20 秒后，唯一明确入口自动加入游戏库；多个入口、非零退出或只有 EXE 时由用户选择。不将安装宿主退出等同于安装成功。
- 关闭安装弹窗不会停止监测；最长监测 30 分钟，可主动停止识别而不结束安装程序。没有可识别快捷方式、安装到容器外或超出扫描上限时仍需手动添加。
- 记录每个自动添加程序的容器和运行时，启动与进程监测使用保存的目标；快捷方式由 Wine start 执行以保留原始参数和工作目录。旧游戏记录兼容缺省字段。
- 仅修改应用代码；不覆盖应用目录，不操作真实安装包，不改变 Runtime 或 Steam 补丁。B0 构建和预检、独立扫描 fixture 验证；不运行 XCTest。第三方完整安装流程仍需手工验证。
