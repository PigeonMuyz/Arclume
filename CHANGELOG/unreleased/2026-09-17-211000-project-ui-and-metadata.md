# 启动器操作、项目编辑与弹窗统一

- 移除游戏详情按钮与旧详情页；更多菜单统一安装目录、运行设置、编辑项目信息，剑网3另含画质设置。
- 主操作与更多使用真实应用图标主色的透明 Liquid Glass，减少非剑网3背景模糊。
- 共享弹窗改为固定标题栏、圆形关闭按钮与独立内容区；设置采用原生侧栏，减少嵌套面板；安装与配置页同步标题样式。
- 项目编辑改为基本信息、外观、资料来源三个分区；展示资料不改变启动路径或容器。
- 接入 GameDB 查询预览、精确 Steam 映射的当前语言补全，以及可复用的内置展示 JSON；保存明确采用的资料来源。
- 兼容旧展示配置，无 Runtime、用户容器或发布版本变更；旧版本可忽略新增展示键回滚。
