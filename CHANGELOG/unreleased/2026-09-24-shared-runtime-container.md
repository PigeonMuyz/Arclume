# Arclume 与 Nefinita 共用容器

- 按用户确认调整上一版独立容器设计：两套运行时共用 ALBottles，只切换 Wine 引擎，不再新建 NefinitaBottles；不会移动、删除或合并已有用户目录。
- 启动、初始化、Steam、安装程序和预热沿用统一运行时路由；界面说明改为共享游戏与数据。
- 切换在后台持有运行时维护门禁，撤销待执行的旧启动请求，检查两套受管引擎的活动进程后才保存选择。目标未就绪或仍有 Windows 进程时保持原选择。
- 补充同容器双向路由、保存路径与容器文件不变、排队启动取消、未就绪和进程繁忙拒绝切换的隔离测试。
- 两套运行时的 Manifest/ABI 不重写。真实 Wine 可能在首次启动时更新共享前缀，切回引擎并非数据回滚；完整构建及 Arclume → Nefinita → Arclume 游戏实测尚未完成。
- 本次不触碰真实容器、不覆盖 Applications、不上传 OSS、不提交或发布。
