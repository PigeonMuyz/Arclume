# 游戏关联数据清理与 JSON 适配规则

- 新增卸载预览分类勾选：本体默认选中，日志、本地数据、登录数据、专属注册表默认保留；可只清数据不删游戏。显示每项路径与大小，文件移至废纸篓，部分失败报告已完成项。
- 注册表仅离线处理精确游戏键及子键，所有 Wine 程序必须退出；保存权限受限的所选键恢复片段，不备份或清空整个容器。未知/共享 SDK 数据、账号云端数据和 Arclume 自身启动设置不动。
- 新增 `Resources/GameAdaptations/hypergryph.json`：鹰角/终末地路径、启动参数、识别文件、元数据 ID、关联数据规则共用一个来源。提供 JSON Schema 和投稿文档。
- NSIS 安装包传入默认安装目录；自动添加、手工保存和启动检查适配目录。第三方安装器仍可能改目录，偏离目录仅拒绝接入，不移动旧文件，不声称文件系统级锁死。保留安装 UI/许可确认。
- 兼容性：已有非规定路径安装需要用户自行重新配置；当前已验证默认终末地路径不变。回滚源码即可恢复旧识别策略；真实文件不自动迁移。Runtime、版本和发布资源未改。
- 验证：隔离 fixture 测试与无签名构建，详见交付说明；未执行用户游戏/数据清理，未重装或下载游戏。后续 UI 测试入口重写及 Runner 认证阻塞另见 110000 记录。
- 17 项关联数据/生命周期/启动规则测试通过（加上后续测试入口断言共 19 项）。覆盖注册表多行值/邻近键、私有权限原子替换、过期预览拒绝、路径别名、符号链接和 NSIS 参数构造。JSON 语法与路径正则验证通过，资源已确认随 App 打包。第三方安装器实际接收参数未通过重装验证。
