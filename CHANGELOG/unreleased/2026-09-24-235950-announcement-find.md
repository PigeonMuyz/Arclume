# 公告正文查找与列表排版

- 公告正文增加 ⌘F 查找入口，支持回车 / ⌘G 查找下一个、⇧⌘G 查找上一个、循环查找与未找到反馈；Esc 先收起查找栏，再退出公告。
- 使用 WebKit 原生查找、高亮与滚动，不执行正文脚本；等正文加载完成后执行查找，忽略过期结果。
- 公告列表标题与时间字号缩小，分别保持单行；过长标题省略，悬停可查看完整标题。
- 不修改用户游戏、容器、运行时或迁移数据；无需数据迁移，回退应用即可撤回本次界面改动。
- 手工验证：隔离公告 fixture 中测试 ⌘F、中文查找、前后匹配、无结果、Esc，以及长标题的单行显示。
- 验证结果：无签名 Debug build、`./script/pr_preflight.sh`、`git diff --check` 通过；`ArclumeCore` 的 `ArticleReaderRenderingTests` 通过。隔离界面已验证正文焦点下的 ⌘F、中文高亮/自动滚动、⌘G/⇧⌘G、回车、无结果提示与两级 Esc；未运行 UI XCTest，未覆盖 Applications。
