# 修复重置时无法打开应用设置

- 当前应用偏好改为使用 `UserDefaults.standard`，不再将自身 Bundle ID 传入 `UserDefaults(suiteName:)`。后者在真实 App 中返回空对象，导致数据移入废纸篓后重置失败。
- 在移动数据前解析两个设置存储，避免设置存储不可用时先移动目录；保留待重置标记与缺失支持目录的重试逻辑。
- 重置错误页不再将所有错误都描述为 Wine 或目录权限问题，并允许说明完整换行。
- 新增实际宿主 Bundle ID 的只读存储选择回归测试，保留临时偏好域隔离；不对真实偏好执行测试写入或重置。
- 兼容性与恢复：不改变容器、Runtime、重置范围或文件格式；先前失败留下的待重置标记会在用户下次打开修复版时继续处理，已移入废纸篓的目录不会再次移动，仍可手动恢复。
- 验证范围：重置与退出核心隔离测试、无签名 Debug 预检；完整旧版升级与游戏启动由用户手工验证。
