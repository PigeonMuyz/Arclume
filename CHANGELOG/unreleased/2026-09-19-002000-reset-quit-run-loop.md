# 修复确认重置后无响应

- 重置确认框关闭后再请求退出，避免在关闭弹层的同一回调中进入退出流程。
- Wine 清理期间取消当前退出请求，保持正常事件循环；清理成功并写入重置标记后再次退出。不再使用会使 MainActor 清理任务无法执行的 `terminateLater` 模态循环。
- 重复退出请求合并处理；清理或重置标记提交失败时取消重置并提示，容器迁移进行中也撤销本次重置意图。
- 数据边界不变：仅用户确认重置后，下次启动才将 Arclume 支持目录移入废纸篓并清除设置；本次开发验证不操作真实容器、游戏或偏好。Runtime 归档与迁移算法不变。
- 验证：独立 AppKit 进程复现旧退出流程任务无法执行、新流程正常退出；运行重置与 Wine 退出核心隔离测试及无签名 Debug 预检。
- 手工验收：确认重置后应退出，再次启动执行原有重置流程；低版本升级、容器迁移和真实游戏启动由用户随后验证。重置后的数据可从废纸篓恢复，恢复源码本身不会还原已经清除的设置。
