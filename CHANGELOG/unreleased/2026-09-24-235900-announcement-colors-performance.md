# 修复公告正文颜色与长文首次展示卡顿

- 类型：fix
- 范围：公告 HTML→Markdown、正文阅读视图

## 改动

- 正文阅读启用受控的文字颜色扩展，支持十六进制、RGB 与常用命名色，保留继承的文字颜色；默认通用转换仍输出纯 Markdown。
- 深色与浅色界面分别校正强调色的可读性，提高“查看原文”链接对比度，不改弹层底色。
- Markdown 解析、颜色整理与 HTML 净化均在后台完成，正文由独立 WebKit 阅读视图排版，替代整篇 SwiftUI 节点及间距回调。
- 仅阅读转换后的静态正文，禁用 JavaScript、导航、表单、持久化网页数据；链接交给系统浏览器，远程图片延迟加载。
- 修复彩色连续粗体文字间出现多余星号的问题。

## 验证和影响

- 增加颜色、净化、对比度与可选真实长公告回归测试；真实官网数据不入库。
- 42 项核心测试通过，包含官网 1335822 长公告（421,134 字节 JSON）的解析与颜色回归；本机 Debug 后台转换约 1.1–1.3 秒，此数据不代表完整网络加载或帧率。
- 无签名 Debug 构建、`script/pr_preflight.sh`、`git diff --check` 通过；隔离演示已检查真实长公告颜色、链接对比度、滚动与关闭，未运行 UI XCTest。
- 不涉及容器、游戏启动、Runtime、用户配置或迁移；无数据迁移。
- 本次没有自动覆盖 Applications、提交或发布。
