# C 方案：预览与编辑分栏

- 项目信息编辑采用常驻外观预览与右侧信息、图片、资料三个面板，使用系统分段控件、按钮和表单。
- 资料匹配可分别采用名称简介、背景和透明标志；缺失素材保留原设置，不更改程序路径或容器。
- 未保存修改关闭前确认；图片链接编辑支持取消和地址校验。
- 设置参考 Steam 的左侧固定分类与右侧页面标题结构，使用原生侧栏与分组表单，保留运行环境、游戏库、更新、重置等能力；共用弹层不再叠加自绘材质背景。
- 兼容性：沿用现有持久化格式，无数据迁移；替换旧 App 可回退界面，已保存外观仍可读取。
- 手工验证：检查 Mac / Windows / 内置适配项目的三页预览，Steam 与 App Store 采用/取消/保存，设置分类切换和关闭确认。
