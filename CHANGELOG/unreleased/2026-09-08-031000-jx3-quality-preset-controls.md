# 对齐客户端预设与画质控件

- 官方预设优先读取所选 Games 容器内客户端 `config/` 的同名文件，缺失时回退 App 内置副本；增加 `config_5_gaoxiao.ini`「高效」预设。不按截图中的临时显示值重写官方文件。
- 配置模型独立为 `JX3QualityConfig.swift`。自身/其他玩家的透明度和明暗度分别读写 Alpha / Light，新增四个独立滑块。
- 增加雨雪、日夜循环、四季变换、体积光、体积雾控件；镜头光斑保留在后期分组。
- 修正特效裁剪距离 4000/5000/8000 的「中」标签，补齐植被密度 25 的「中」档。阴影数量 90 显示「高」、100 显示「超高」；不再随植被密度猜测改写树木密度。
- 物件细节的独立配置键尚未验证，暂随预设，不再误写整体画质索引 `nEngineGraphicsLevel`。显式 `HDRepresent=0` 正确识别为手绘模式。
- 保留前一轮增量保存、DLSS 能力声明与实际画质分离的修复；不修改用户当前游戏配置，不调整显卡伪装、D3DMetal 注入或 Runtime 版本。
- 验证：PR 前置审核（无签名 Debug 构建，不执行 XCTest）；临时配置检查独立滑块、裁剪距离、预设读值、增量更新和原始编码/换行保留。界面与游戏内生效仍需真机操作确认。
