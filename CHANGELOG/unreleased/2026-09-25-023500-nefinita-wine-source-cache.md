# Wine 源码镜像及共享缓存

- Nefinita 构建优先从 OSS 获取固定的 CodeWeavers 26.3.0 开源源码包，网络失败回退官方源。
- 源码包按 SHA-256 持久缓存，跨构建重试复用；下载落盘、检查大小及哈希，未完成或损坏文件不作为可用缓存。
- 保持上游配方及脚本不变，仅预填每次构建的下载目录；源码版本与已认证的 WINE_SOURCE.lock 必须一致。
- 不分发商业安装包，不修改运行时 ABI、现有容器或游戏；旧 App 仍使用原官方地址，不依赖新缓存。
- 发布只增加这份不可变源码对象，执行配额、远端及公开下载校验，不清理远端历史对象。
- 手工验证：首次选择 Nefinita 显示加速源下载，重试显示使用缓存；阻断镜像后可回退官网。完整 Wine 构建与游戏运行需另行验收。
- 验证：16 项 Swift 核心测试、29 项 Python 测试、无签名 Debug 预检与本地签名构建通过；源码对象上传、存储端回读、匿名 HTTPS 及 macOS URLSession 下载大小和 SHA-256 均通过。未替换 Applications 中的 App，未触发完整 Wine 构建。
