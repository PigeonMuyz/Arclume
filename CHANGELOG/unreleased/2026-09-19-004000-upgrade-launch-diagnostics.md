# 补充旧版升级与启动诊断

- 系统日志增加 `RuntimeUpgrade` 和 `ContainerUpgrade` 分类，记录运行时版本选择、旧运行时复用、更新完成，以及迁移检查、合并和收尾结果；不记录每个游戏文件或注册表内容。
- 剑网3启动日志补充运行时准备和进程创建失败的错误域、错误码及有限深度的底层错误，避免只显示本地化提示。
- Debug 启动诊断增加 App 版本、运行时版本标记与 x86_64 执行检查；区分当前进程转译状态与 Rosetta 可用性。
- 本改动不改变 Runtime 归档、旧运行时接管、容器迁移或启动逻辑，不执行真实升级。用户保留 1.0.3 (8) 初始化后的现场，手工完成升级与启动复现。
- 验证：无签名 Debug 预检、带原开发证书的本地构建与安装后签名检查；实际日志产生和游戏启动结果等待用户复现。移除本次日志代码即可回退，不涉及数据格式变化。
