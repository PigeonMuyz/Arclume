# Nefinita 本机编译入口与运行时选择

- 设置和初始化可选择下载 Arclume Runtime，或本机编译 Nefinita（暂定名称）。旧用户默认仍为 Arclume。
- 接入固定上游提交的源码目录检查、工具预检、分阶段后台构建、文件日志和构建产物检查。仅复制校验通过的构建输入，不携带 GitHub 凭据，不读取源码目录内已有编译产物。
- Nefinita 使用独立运行时目录和 NefinitaBottles；不同 prefix ABI 不自动合并或改写。已有应用按原容器选择运行时，安装器、Steam 和预热使用相同规则。
- 不修改当前 Arclume Runtime Manifest、版本号、运行归档或用户容器；不上传 OSS、不发布、不覆盖 Applications。
- 当前需本地提供获授权的 Nefinita 源码目录及构建工具。私有上游尚不能由终端用户匿名获取；OSS 构建包、工具包的发布是后续步骤。
- 真机验收：在隔离用户环境准备工具及固定版本源码，完成全量编译，分别初始化两种运行时并运行 32/64 位应用；验证重启、切换和失败回退。当前未进行完整 Wine 编译与游戏验收。
