# 移除 CrossOver 修补功能

- 时间：2026-09-24T22:00:00+08:00
- 类型：fix
- 范围：App

## 改动

- 删除 CXPatcher 修补实现和专用依赖安装链，移除准备 CrossOver 副本、改写版本/配置、关闭更新与重新签名功能。
- 选择已有 CrossOver 时直接读取原应用和 Bottle 配置；启动游戏时不再替换外部 CrossOver 的 D3DMetal 或 MoltenVK。
- 删除修补依赖导入/下载界面及无效 Vulkan 库切换项；将仍在使用的用户支持路径、历史迁移与图形缓存工具保留到通用目录。

## 用户影响与兼容性

- 不删除、回滚或重写用户已有 CrossOver 应用、历史修补副本、Bottle 或游戏数据。已有 CrossOver 将使用其当前安装的图形组件。
- Arclume Wine 独立的归档提取、D3DMetal 安装和游戏启动路径保持可用；不修改运行资源二进制或 Runtime Manifest。
- 回滚此代码不会恢复或覆盖任何用户目录；需要旧修补行为时必须另外明确选择历史版本。

## 验证

- 新增隔离 Bottle 配置读取测试，检查读取前后应用配置和 Bottle 数据完全一致。
- 全仓检查修补函数/调用引用与差异空白；无签名 Debug 构建和所选核心测试由本次整体交付统一执行。
- 手工验证：选择既有 CrossOver 并检查原应用不产生复制/组件改写；分别检查标准游戏与在线游戏使用现有环境启动。真实 CrossOver/游戏启动未执行。
