# 绿色 Windows 软件导入和整包更新

- 安装入口接受 ZIP/7z/RAR，在私有临时目录逐项校验解压，拒绝链接、越界、重复路径及超限内容，不执行附带脚本。
- 新增声明式 portable 规则和 YY 语音入口适配；未知包支持选择 EXE，固定独立目录导入。已适配软件再次导入提供确认后的整包替换更新，库入口不变。
- 用同卷原子交换保留旧安装作为恢复副本；保持 AppData、注册表及规则指定的安装内数据，拒绝覆盖非托管目录和运行中的 Windows 程序。绿色软件接入现有卸载预览。
- 未改变 Runtime、Manifest、发布版本或用户现有容器。自动化只使用隔离 fixture；真实 YY 登录、语音与注册步骤仍需手工验证。RAR 的具体压缩方式/分卷/加密支持以系统解码结果为准。
- 手工验收：选择可信 YY 包 → 预览固定目录 → 导入 → 库中启动；退出 Windows 程序后选择新版包 → 确认替换 → 检查原入口和数据。回滚时退出 Wine，将保留的 previous 目录恢复到固定安装路径，先另存当前版本。
